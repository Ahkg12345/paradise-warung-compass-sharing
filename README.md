# Kedai Paradise Foundation

### Integrated Cashier and Financial Management System

A web-based application designed to support daily cashier operations, transaction management, and financial record-keeping for Kedai Paradise Foundation.

## Overview

Kedai Paradise Foundation is a digital management system focused on improving operational efficiency, simplifying sales transactions, and organising financial information.

## Key Features

- Secure user authentication
- Cashier management
- Sales and transaction recording
- Financial summaries and reporting
- Organised management dashboard
- Responsive user interface

## Technology Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Database and backend integration

## Local Development

### Requirements

- Node.js
- npm

### Installation

```bash
git clone https://github.com/Ahkg12345/paradise-warung-compass.git

cd paradise-warung-compass

npm install

npm run dev
```
